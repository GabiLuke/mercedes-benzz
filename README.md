# 🚗 Mercedes CLS — Landing page responsive

Página de aterrizaje (*landing*) estática inspirada en la web de Mercedes-Benz, hecha con **HTML5 y CSS3**. Práctica centrada en maquetación, diseño responsive y efectos visuales.

## ✨ Contenido

- 🧭 Navbar y secciones tipo *hero* con imágenes a pantalla completa
- 📜 Efectos de scroll y galería de modelos
- 📱 Maquetación **responsive** con media queries

## 🛠️ Stack

HTML5 · CSS3 (Flexbox, Grid, media queries)

## 🚀 Uso local

Abre `Mercedes/index.html` en el navegador, o sírvelo con cualquier servidor estático.

---

## 🎯 Qué demuestra

Dominio de **maquetación semántica** y **CSS moderno** (layout, posicionamiento y diseño adaptable) sin frameworks.
